# Terraform EKS

## Project Status

Active development.
Project

This project provisions an EKS cluster using Terraform.

## Structure

- `udemy/`: Contains the main Terraform configuration.
- `udemy/vpc`: VPC module.
- `udemy/eks`: EKS module.

## Usage

1. Initialize Terraform:

   ```sh
   terraform init
   ```

2. Plan the deployment:

   ```sh
   terraform plan
   ```

3. Apply:
   ```sh
   terraform apply
   ```
